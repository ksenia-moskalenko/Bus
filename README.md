## Работа с ИИ

При разработке интерактивного лонгрида «Автобус» использовался **ChatGPT (OpenAI)**. Искусственный интеллект выступал в роли помощника при написании и редактировании кода, создании графических материалов и поиске технических решений.

### Для каких задач использовался ИИ

**1. Разработка интерактивных элементов**

ChatGPT помогал реализовывать интерактивные механики сайта: выбор места в автобусе, отображение пассажиров, рейтинг соседей и эксперименты с личным пространством.

**2. Вёрстка и адаптация**

ИИ использовался для написания и корректировки HTML, CSS и JavaScript. Особое внимание уделялось мобильной версии: расположению элементов, масштабированию изображений, повороту схем автобуса и адаптации типографики под небольшие экраны.

**3. Создание изображений**

С помощью генеративного ИИ создавались и редактировались изображения пассажиров, фотографии для лонгрида и визуальные материалы для презентации проекта. Полученные изображения дополнительно отбирались и дорабатывались.

**4. Редактирование текстов**

ChatGPT помогал корректировать формулировки, сокращать тексты и исправлять типографические ошибки, в том числе висящие предлоги и некорректные переносы тире.

### Примеры запросов к ИИ

- «Сделай так, чтобы при выборе места в автобусе появлялся соответствующий текст, а занятые места были недоступны для нажатия».
- «Адаптируй интерактивную схему автобуса для мобильной версии, повернув её на 90 градусов, но сохранив расположение кликабельных областей».
- «Измени положение текста и стрелок на карточках пассажиров, не затрагивая остальные элементы сайта».
- «Проверь текстовые блоки на наличие висящих предлогов и исправь переносы с помощью неразрывных пробелов».
- «Создай чёрно-белое изображение пассажира в автобусе в стилистике проекта».

### Процесс работы

Работа с ИИ строилась итеративно: сначала формулировалась задача, затем проверялся полученный результат и при необходимости вносились уточнения.

Например, при адаптации интерактивного автобуса для мобильных устройств потребовалось несколько последовательных изменений, чтобы правильно расположить схему, изображения пассажиров и текстовые блоки.

ИИ помогал ускорить техническую реализацию, однако визуальные решения, композиция, структура повествования и оценка итогового результата оставались за автором проекта.

### Итог

Использование ChatGPT позволило быстрее реализовывать интерактивные механики, экспериментировать с вёрсткой и устранять технические ошибки. При этом ИИ использовался как вспомогательный инструмент, а не как замена самостоятельному проектированию.
